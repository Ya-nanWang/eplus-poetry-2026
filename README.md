🌸 2026 经典诵读月：凌空诗境

“手可摘星辰，亦可听诗吟。”


“凌空诗境” 是我为大语文班2026年“经典诵读月”成果制作的一个集视觉、听觉和交互于一体的网页作品。通过将孩子们的诵读录音放进星星里，访客可以使用手势、鼠标或触摸互动，聆听每一个声音。

作为志愿者老师，我希望通过这个小小的项目，让经典不再只是文字，而成为可触摸、可聆听、可回忆的星光。

每一颗星星，都是一次认真朗读、一次勇敢展示，也是他们成长路上的一小步。

很开心能用这样的方式，把孩子们的声音留下来。 希望多年以后再点开这个页面，还能想起在荷兰一起学习中文的春天🍃


🛠 技术小笔记
- 使用 MediaPipe Hands 实现实时手势识别

- 通过 Canvas 绘制粒子动画与视觉特效

- 纯前端实现，无需后端支持

- 响应式设计，适配各类屏幕
